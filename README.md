# Ventura Creative Agency

Лендинг креативного агентства Ventura (Алматы). Статика без сборки и зависимостей.

- `index.html` — вся страница, единственный источник правды
- `assets/` — три альфа-маски логотипа, видео героя, кадры для архива
- `build-tilda.py` — собирает версию для блока T123 в Tilda (`tilda/`)

## Локально

```bash
python3 -m http.server 8799
```

## Логотип

Знак собирается из трёх альфа-масок (`mask-pink`, `mask-letters`, `mask-subtext`),
цвета задаются CSS-переменными `--pink` / `--ink`. В буквы через `mask-image`
залито видео. Перекрасить логотип = поменять переменную.
